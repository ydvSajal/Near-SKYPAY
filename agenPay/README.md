# SkyPay application source

This directory contains the current native NEAR application:

- [agenpay-backend](agenpay-backend): Express API, Prisma ledger, agent tools, NEAR adapter, email/Notion outbox and scripts.
- [agenpay-frontend](agenpay-frontend): Next.js company workspace and public invoice checkout.

Start with the [project README](../README.md), [setup guide](../docs/SETUP.md), [demo](../docs/DEMO.md) and [documentation index](../docs/README.md). Run commands from the directory stated in each guide.

The earlier Sei/EVM documentation is historical: see [legacy baseline](../docs/legacy/README-sei-baseline.md) and [migration decisions](../MIGRATION.md). It is not the setup guide for the current NEAR app.
